# Студент ТУСУР — модуль двухфакторной аутентификации

Мобильное приложение «Студент ТУСУР» для студентов Томского государственного
университета систем управления и радиоэлектроники. В рамках проекта был
разработан и внедрён модуль двухфакторной аутентификации (2FA), а также
проведено полное обновление зависимостей и SDK до актуальных версий.

## О проекте

- **Задача:** внедрить в существующее приложение модуль 2FA и привести проект
  к актуальному состоянию по зависимостям и SDK.
- **Роль:** Flutter-разработчик (полный цикл: от анализа текущего кода до
  релиза модуля).
- **Платформы:** Android, iOS.

## Что было сделано

### Модуль двухфакторной аутентификации
- **Шаги**: авторизация, отправка кода на email, экран ввода кода,  повторная отправка, таймер, обработка ошибок
- **Хранение токена**: secure storage 
- **Интеграция с бэкендом: какие эндпоинты использовались**

### Обновление зависимостей и SDK
- Полное обновление `pubspec.yaml` до последних/предпоследних версий пакетов.
- Обновление Flutter SDK и Dart SDK до актуальной стабильной версии.
- Устранение breaking changes после апгрейда.
